# הדפסת מדבקות למעבדה 204 — Brother PT-P900Wc

הוכנו שלושה קובצי PDF חלופיים לסרטי TZe ברוחב 18, 24 או 36 מ״מ. בחר רק את הקובץ שרוחבו מתאים לקסטה המותקנת במדפסת. בכל קובץ אותן 35 מדבקות, מדבקה אחת בכל עמוד, באורך 85 מ״מ.

## מה כלול

- עמודים 1–7: מדבקה לכל ארון, Rack-01 עד Rack-07.
- עמוד 8: מדבקה אחת בלבד לאחסון הראשי — MAIN STORAGE.
- עמודים 9–35: מדבקה לכל מדף. מדף 01 הוא המדף העליון.

מספר המדפים מבוסס על התיאור הפיזי בפרויקט: ארבעה בכל ארון, פרט ל־Rack-05 שבו שלושה. Rack-08 מסומן שם כמתוכנן וללא מיקום פיזי, ולכן אינו כלול. יש להתאים את המדבקות למספרי הארונות והמדפים בפועל לפני ההדבקה.

## הדפסה

### מהטלפון

1. הורד ופתח את חבילת ה־ZIP. בחר בתיקייה `18mm`, `24mm` או `36mm` לפי רוחב סרט ה־TZe המותקן במדפסת. בכל תיקייה אותן 35 מדבקות בפורמט PNG; אין צורך להדפיס את כל שלוש הגרסאות.
2. שמור את תמונת המדבקה הרצויה בגלריית התמונות של הטלפון.
3. חבר את הטלפון והמדפסת לאותה רשת Wi-Fi, פתח **Brother iPrint&Label** ובחר את PT-P900Wc.
4. צור מדבקה, ייבא את התמונה מהגלריה והגדר את רוחב הסרט המתאים ואורך של 85 מ״מ. שמור על יחס התמונה ועל הברקוד בשלמותו; אל תחתוך את השוליים הלבנים סביבו.
5. הדפס תחילה מדבקה אחת וסרוק אותה לבדיקה. אחרי שהבדיקה מצליחה אפשר להמשיך לאחרות. קובצי ה־PDF נמצאים גם בתיקיית `PDF` בחבילה; להדפסה דרך ייבוא תמונה באפליקציה השתמש בקובצי PNG.

Brother מתעדת יצירת מדבקות מגלריית הטלפון באמצעות [iPrint&Label](https://www.brother.com.my/en/solutions/labelling-detail), ו[הדגם מופיע ברשימת התמיכה באפליקציה](https://support.brother.com/g/b/faqend.aspx?c=us&faqid=faqp00001579_000&lang=en&prod=p900weus). ההדפסה באפליקציה ובמדפסת הפיזית עדיין דורשת את בדיקת המדבקה הראשונה.

### קובצי PDF

1. בדוק על קסטת ה־TZe את הרוחב במ״מ ופתח את ה־PDF המתאים. אם הסרט הוא ברוחב אחר, יש להכין קובץ מתאים; אין להקטין גרסה רחבה יותר.
2. בחלון ההדפסה בחר את מדפסת Brother PT-P900Wc.
3. בהעדפות המדפסת בחר את רוחב הסרט המותקן ואורך מדבקה של 85 מ״מ. התצוגה המקדימה צריכה להציג מדבקה אופקית: 85 מ״מ משמאל לימין, ורוחב הסרט מלמעלה למטה.
4. בחר **Actual size / 100%**, עמוד אחד למדבקה והעתק אחד. בטל התאמה לגודל דף, הדפסת כמה עמודים בדף וכותרות נוספות.
5. הדפס תחילה רק את עמוד 1. ודא שהברקוד שלם ושסריקתו מחזירה `RACK:Rack-01`. לאחר הבדיקה הדפס את עמודים 2–35, כדי לא להכפיל את המדבקה הראשונה.

הקבצים כוללים ברקוד Code 128, שוליים נקיים והתאמה לרזולוציית 360dpi. כל 35 הברקודים בכל אחת משלוש הגרסאות פוענחו מתוך הקובץ המרונדר. ההדפסה במדפסת הפיזית עדיין לא נבדקה.

## הפעלת מדבקות הארון והאחסון באתר

מדבקות המדף תואמות לגרסה שכבר הותקנה. מדבקות הארון השלם והאחסון הראשי דורשות את עדכון המעקב הנוסף שהועלה ל־GitHub, commit `634b755` או גרסה מאוחרת יותר המכילה אותו. הן אינן מדבקות ציוד ואין לקשר אותן לפריט חדש.

הרץ פעם אחת בטרמינל של ה־VM, ללא sudo:

```bash
cd "$HOME/DCIM-204" && git fetch origin feat/barcode-inventory && git show FETCH_HEAD:scripts/install-barcode.py | backend/.venv/bin/python - "$(git rev-parse FETCH_HEAD)" --backup-frontend-lock
```

לאחר הודעת Installed, רענן את מסך Scan & Track באתר שלך, או הוסף לכתובת האתר `/?tab=scan`.

1. סרוק את מדבקת המדף, הארון או האחסון שאליו תרצה להכניס את הציוד. היעד יוצג בראש המסך.
2. סרוק את הברקוד או המספר הסידורי של הציוד. ברקוד חדש נרשם ונשמר אוטומטית ביעד שבחרת, עם הברקוד כשם וסוג **Other**. אפשר לערוך שם וסוג בהמשך ב־DCIM.
3. אם הציוד כבר קיים, בדוק את היעד ולחץ **Save and confirm location** כדי להעביר אותו. ציוד חדש שנרשם אוטומטית כבר נשמר ואינו דורש אישור נוסף.

האפשרות **Automatically register new equipment** פעילה כברירת מחדל. כדי לקשר ברקוד לא מוכר לפריט שכבר רשום תחת מזהה אחר, כבה אותה לפני הסריקה והשתמש ב־**Link barcode**.

המיקום נשאר נבחר גם לסריקת היחידה הבאה. סרוק מיקום אחר להחלפת היעד, או לחץ **Clear destination** לניקוי היעד והציוד הנבחר. נדרש עדכון האתר הכולל את תהליך הסריקה החדש; גם סריקת ציוד לפני מיקום עדיין נתמכת.

מדבקת מדף בוחרת ארון ומדף יחד. מדבקת ארון בוחרת ארון ללא מדף מסוים; אפשר לסרוק אחריה מדבקת מדף לפני סריקת יחידה חדשה או שמירת העברת ציוד קיים. מדבקת MAIN STORAGE בוחרת יחידת אחסון ראשית אחת, ללא חלוקה למדפים. היא אינה משנה אוטומטית מיקום של ארון במודל התלת־ממדי. רישום יחידה חדשה מתבצע אוטומטית כשיש יעד נבחר; העברת ציוד קיים דורשת אישור שמירה.
